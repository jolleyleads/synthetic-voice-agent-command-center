# Synthetic Voice Agent Command Center

## Overview
Synthetic Voice Agent Command Center is a voice-enabled AI assistant that connects to the AI Ops Command Center and can run tool-style actions through backend APIs.

## What It Does
- Listens to voice commands
- Speaks replies back to the user
- Searches remote AI/ML jobs
- Calls the AI Ops Command Center API
- Checks workflow events
- Analyzes messages for spam/not spam
- Acts as an Alexa-style AI automation assistant

## Tech Stack
- Python
- Flask
- OpenAI API
- Browser Speech Recognition
- Browser Text-to-Speech
- HTML/CSS/JavaScript
- Render-ready backend
- AI Ops Command Center API integration

## Main API Endpoint
POST /api/agent

## Example Request
{
  "message": "Find me remote machine learning jobs"
}
